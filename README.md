# 🏃 Temple Run Inspired Game

A browser-based endless runner game inspired by **Temple Run**, built using HTML, CSS, and JavaScript. Dodge obstacles, collect coins, and run as far as you can!

## 🎮 Live Demo

**Play the game:** [Deploy your game with GitHub Pages](https://pages.github.com/)

> Replace this section with your live GitHub Pages URL after deployment.

## ✨ Features

- 🏃 Endless running gameplay
- 🪙 Coin collection and scoring system
- 🚧 Obstacles to dodge
- ⬆️ Jump and slide mechanics
- ⌨️ Keyboard controls
- 📱 Mobile-friendly touch controls
- 🔄 Restart option after game over
- 🌿 Temple and jungle-inspired visuals
- ⚡ Built with HTML5 Canvas — no external libraries required

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Game logic and controls
- **HTML5 Canvas** — 2D game rendering

## 🚀 Run Locally

1. Download or clone this repository.
2. Make sure all three game files are in the same folder.
3. Open `index.html` in your browser.
4. Click **Start Run** and enjoy the game!

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

## 🎯 How to Play

| Action | Control |
|---|---|
| Jump | Up Arrow (↑) or W |
| Slide | Down Arrow (↓) or S |
| Move left | Left Arrow (←) |
| Move right | Right Arrow (→) |
| Restart | Use the restart button after game over |

*Note: Controls depend on the actions implemented in the current version of the game.*

On mobile devices, use the on-screen controls or swipe gestures where supported.

## 🌐 Deploy on GitHub Pages

1. Create a new repository on [GitHub](https://github.com/).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder.
3. Open your repository and go to **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and the `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to publish your site.

Your game will be available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```
